# CODEMAP: one line per important file or folder

## Root
- `CLAUDE.md` short rules for AI agents · `STATUS.md` current milestone + next step · `docs/SPEC.md` full spec
- `Makefile` setup/start/stop/test/reset/update/mock · `docker-compose.yml` api + web (+ ai profile: languagetool, ollama)
- `.github/workflows/ci.yml` lint, types, unit, integration, e2e · `package.json`, `pnpm-workspace.yaml` JS workspace

## Database (`supabase/`)
- `migrations/20261122000001_core_schema.sql` types, tables, updated_at triggers, signup trigger, `has_role`/`is_staff`
- `migrations/20261122000002_rls_policies.sql` grants + RLS policies for every table
- `seed.sql` GENERATED by `scripts/build_seed.py` (do not edit) · `templates/*.html` auth emails · `config.toml`

## Content (`content/`)
- `levels.json` 6 levels (CEFR) · `question_categories.json` 22 task types + official source
- `diagnostic.json` placement test (18 original items, levels 1-6, with answers) · `lessons/level-1.json` 2 units, 5 lessons (Learn/See/Try/Check) + end-of-unit tests · `questions/*.json` 44 original sample questions
- `LICENSE.md` CC BY-SA 4.0

## Backend (`apps/api/app/`)
- `main.py` app factory, middleware (CORS, security headers, logging, rate limit), routers, GraphQL mount
- `core/config.py` settings from env · `core/security.py` JWT/JWKS verification, `get_current_user`
- `core/errors.py` error format · `core/logging.py` JSON logs, no PII · `core/ratelimit.py` sliding window
- `db/session.py` `user_session` (RLS as authenticated) / `service_session` · `db/models.py` SQLAlchemy models
- `api/deps.py` DB dependency, `require_role` · `api/me.py` onboarding PUT, export GET, delete · `api/health.py`
- `api/practice.py` answer a question · `services/practice.py` auto-marking (blanks, choices, reorder, highlight words, dictation), attempts, speech text
- `api/placement.py` submit, item speech · `services/placement.py` level recommendation + study plan (pure)
- `api/units.py` end-of-unit test · `services/units.py` unlock rule (pure) + test marking + unit progress
- `services/review.py` mistake notebook + spaced review schedule (Leitner boxes 0-5)
- `api/lessons.py` lesson start, Try check, Check submit · `services/lessons.py` marking (answers never leave the API)
- `graphql/schema.py` Query: viewer (dashboard fields), learningLevels, questionCategories, lessons, lesson, practiceTypes, practiceQuestions, viewer.reviewItems/reviewDueCount/studyPlan, placementTest, units, unit; limits
- `graphql/context.py` per-request context, locked execute, DataLoaders (levels, categories, lesson progress)
- `services/progress.py` streak, skill stats, weak areas (pure) · `services/profile.py` onboarding/export/delete
- `ai/interfaces/` Protocols + result types (EvaluationResult = SPEC 7.2) · `ai/providers/mock.py` deterministic mocks
- `ai/providers/local.py` placeholder (M3) · `ai/registry.py` env-based provider choice · `ai/evaluation/bands.py`
- `export_contracts.py` writes GraphQL SDL + OpenAPI for frontend codegen
- `tests/` unit, security (JWT), integration (RLS, GraphQL, onboarding, export, delete) · `tests/helpers.py` test keys

- `scripts/setup.sh`, `setup.ps1` one-command setup · `write-env.sh` env files from `supabase status`
- `scripts/generate_audio.py` (`make audio`) Kokoro listening audio → apps/web/public/audio (git-ignored)
