# Contributing

Thank you for helping learners! Please:

1. Read `CLAUDE.md` (short rules) and the relevant part of `docs/SPEC.md`.
2. Run `make setup`, then `make dev`.
3. Create a branch, make a small change, add tests, and run `make lint typecheck test`.
4. Open a pull request using the template. Report real test output.

**Content:** only original questions and lessons (see `docs/CONTENT_GUIDE.md`). Never add copied exam questions.
**Never commit** secrets, `.env` files, user data, recordings or model files.
By contributing you agree your code is MIT-licensed and your content is CC BY-SA 4.0.
